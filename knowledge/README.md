# База знаний Academy Eagles

База собрана из публичных страниц [academy-eagles.ru](https://academy-eagles.ru/)
2 сентября 2026 года. Это исходный материал для проверки владельцем, а не
автоматически подтверждённая оферта.

## Структура

- `static/` — устойчивые сведения об академии, услугах и инфраструктуре. После
  проверки их можно загружать в векторное хранилище OpenAI.
- `dynamic/` — цены, сотрудники, мероприятия и часы работы. Эти данные могут
  меняться, поэтому бот должен получать их из структурированного источника, а не
  считать старый текст безусловно актуальным.
- `review-needed.md` — найденные противоречия, заглушки и недостающие данные.

## Правило для будущего бота

Если запись имеет статус `needs_confirmation`, `conflict`, `incomplete` или
`past`, бот не должен выдавать её как актуальный факт. Он должен сообщить, что
информация уточняется, и предложить передать вопрос сотруднику.

Скрипт `scrape_academy_eagles.py` создаёт технический JSON-снимок публичного
сайта. Пример запуска:

```bash
python3 scrape_academy_eagles.py --output /tmp/eagles-academy-snapshot.json
```
